📚 Les concepts derrière ce quiz

Ce quiz utilise les 5 mêmes concepts vus en classe. Ouvrez chaque bloc pour voir le code correspondant.

🧱 Variables

Le programme garde en mémoire où on en est dans le quiz et le score accumulé :

let indexQuestion = 0;
let score = 0;

Ces deux variables changent à chaque réponse et à chaque question.

🔀 Conditions

Quand on clique sur une réponse, le programme compare le choix à la bonne réponse :

if (indexChoisi === question.bonneReponse) {
  score++;
  afficherRetour(true);
} else {
  afficherRetour(false);
}

C'est cette condition qui décide si le score augmente ou non.

🔁 Boucles

Une boucle parcourt la liste des choix de réponse pour créer un bouton par option, sans jamais réécrire le même code 4 fois :

question.options.forEach((texteOption, i) => {
  const bouton = document.createElement("button");
  bouton.textContent = texteOption;
  bouton.addEventListener("click", () => verifierReponse(i));
  optionsEl.appendChild(bouton);
});

La même boucle fonctionne peu importe le nombre de choix ou de questions.

⚙️ Fonctions

Chaque étape du quiz est une fonction réutilisable, appelée encore et encore au fil des questions :

function afficherQuestion() { ... }
function verifierReponse(indexChoisi) { ... }
function questionSuivante() { ... }
function recommencer() { ... }

afficherQuestion() est appelée une fois par question, mais c'est toujours le même code.

🖱️ Événements

Le quiz avance seulement quand l'utilisateur·rice clique quelque part :

bouton.addEventListener("click", () => verifierReponse(i));
suivantBtn.addEventListener("click", questionSuivante);
recommencerBtn.addEventListener("click", recommencer);

Sans ces événements, la page resterait figée sur la première question.
