Les concepts derrière ce projet

Cette page utilise les 5 concepts de base vus en classe. Ouvrez chaque bloc pour voir le code correspondant.

Variables

Le programme garde en mémoire la liste des noms et le nombre d'équipes voulu, dans des variables :

let noms = [];
let nombreEquipes = 2;

Chaque fois qu'on ajoute un nom ou qu'on change le nombre d'équipes, ces variables changent de valeur.

Conditions

Avant d'ajouter un nom ou de lancer le tirage, le programme vérifie que tout est valide :

if (nom === "") {
  afficherErreur("Écrivez un nom avant d'ajouter.");
} else if (noms.includes(nom)) {
  afficherErreur("Ce nom est déjà dans la liste.");
} else {
  noms.push(nom);
}

Sans ces conditions, on pourrait ajouter des noms vides ou en double, ou former des équipes impossibles (ex. plus d'équipes que de personnes).

🔁 Boucles

Deux boucles for font le vrai travail du tirage : une pour mélanger les noms au hasard (algorithme de Fisher-Yates), une pour les distribuer une par une dans chaque équipe :

// Mélanger les noms
for (let i = noms.length - 1; i > 0; i--) {
  const j = Math.floor(Math.random() * (i + 1));
  [noms[i], noms[j]] = [noms[j], noms[i]];
}

// Distribuer les noms un à un, équipe par équipe
for (let i = 0; i < noms.length; i++) {
  equipes[i % nombreEquipes].push(noms[i]);
}

C'est cette deuxième boucle qui garde les équipes équilibrées, peu importe le nombre de noms.

⚙️ Fonctions

Les actions répétées sont regroupées dans des fonctions réutilisables, plutôt que d'être réécrites à chaque fois :

function ajouterNom() { ... }
function formerEquipes() { ... }
function reinitialiser() { ... }

Par exemple, formerEquipes() contient tout le mélange et la distribution ; elle peut être appelée autant de fois qu'on veut (à chaque clic sur le bouton), sans dupliquer le code.

🖱️ Événements

Rien ne se passe tant que l'utilisateur·rice n'agit pas. Chaque bouton (et la touche Entrée) est branché à une fonction par un événement :

ajouterBtn.addEventListener("click", ajouterNom);
nomInput.addEventListener("keydown", (e) => {
  if (e.key === "Enter") ajouterNom();
});
formerBtn.addEventListener("click", formerEquipes);
resetBtn.addEventListener("click", reinitialiser);

C'est ce qui rend la page interactive : le code réagit aux clics et aux touches du clavier, au lieu de s'exécuter une seule fois au chargement.
