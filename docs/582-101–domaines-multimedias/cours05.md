## Partie théorique (50%)

25 questions à choix de réponse sur les sujets vus depuis le cours 1 :

- Histoire de l'informatique 
- Composantes d'un ordinateur 
- Langages de programmation 
- Concepts de base en programmation 
- Données et préfixes de données 
- Systèmes d'exploitation 
- Formats de fichiers 
- Formatage et partition
- Réseaux et web 
- Branchements 
- Markdown, Git vs GitHub, GitHub Pages

## Partie pratique — section individuelle (25%)

### Classement de fichiers (10%)
- Télécharger le dossier de classement de fichiers dans le dossier Examen du groupe Teams
- Classer les fichiers dans les dossiers correspondants selon leur format
- Compresser le dossier et le remettre dans le devoir du cours

### Réservation de matériel (10%)
- Faire une demande de matériel pour le cours de Photographie (caméra et trépied) pour la première date de sortie possible et copier le lien dans le canal Réservation du Teams du cours

### Réservation de local (5%)
- Réserver le Cubicule-1 pour une heure, en date d'hier, à l'heure du cours

## Partie pratique — section supervisée (25%)

### Formatage d'une clé USB (15%)
- Formater une clé USB aux formats demandés avec le gestionnaire de disques
### Rangement et classement des fils présentés (10%)
- Ranger et classer les fils présentés

### Critères de performance

Pour chacune des deux sections, la performance est distribuée ainsi :

- Procédures réussies sans erreur/intervention : 100 %
- Procédures réussies avec une erreur/peu d'intervention : 75 %
- Procédures réussies avec beaucoup d'erreurs/d'intervention : 50 %
- Procédures difficilement réussies, avec beaucoup d'erreurs/d'intervention : 25 %
- Procédures non réussies : 0 %

La qualité de la langue est évaluée jusqu'à concurrence de 10 % de la note finale du travail (1 % par faute).
