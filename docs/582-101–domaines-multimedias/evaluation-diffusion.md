# TP1 : diffusion portant sur l'analyse des caractéristiques du domaine

Vous répondez à un questionnaire sur vos intérêts dans les domaines du multimédia, dans un dépôt GitHub publié avec GitHub Pages. Vous présentez ensuite votre page dans une capsule vidéo enregistrée avec OBS Studio. L'évaluation est individuelle et vaut **15 % de la note**.

## Consignes

1. Créer un nouveau dépôt **public** nommé `analyse-domaine`, avec un fichier `README.md`.
2. Copier le [modèle de README](#modele-de-readme) dans le `README.md`, puis répondre au [questionnaire](#questionnaire) (2-3 lignes par réponse).
3. Publier la page avec GitHub Pages : **Settings** → **Pages** → *Branch* **main** et **/ (root)** → **Save** (voir [Publier sur GitHub Pages](cours04.md#publier-sur-github-pages) au cours 4).
4. Enregistrer la capsule de 3 à 5 minutes avec OBS Studio : une **capture de fenêtre** du navigateur qui affiche votre page GitHub Pages. Faites défiler la page en présentant vos réponses. La webcam est facultative : si vous n'en avez pas, vous pouvez en emprunter une auprès des TTP (techniciens en travaux pratiques).
    - Toute musique ou image ajoutée doit être libre de droits et citée à la fin de la capsule, avec la méthode du [cours 8](cours08.md#etape-4-trouver-des-ressources-libres-de-droits).
    - Nommer le fichier `NOM_Prenom_Capsule.mp4`, sans accent.
5. **Preuve OBS** : pendant l'enregistrement, faire une capture d'écran de l'interface d'OBS (scène, sources et mixeur audio visibles) avec **Windows + Maj + S**. La téléverser dans le dépôt sous le nom `obs.png` : elle s'affiche dans la section « Ma capsule » de votre page.
6. Remettre sur Teams : **le lien de votre page GitHub Pages** et **la capsule .mp4**.

## Enregistrer avec OBS Studio

1. Ouvrir votre page GitHub Pages dans le navigateur.
2. Dans OBS, sous **Sources**, cliquer sur **+** → **Capture de fenêtre** et choisir le navigateur.
3. Vérifier que le micro réagit dans le **Mixeur audio**. Les barres doivent rester dans le vert ou le jaune, jamais dans le rouge.
4. Dans **Paramètres** → **Sortie**, choisir le format d'enregistrement **mp4**.
5. Cliquer sur **Démarrer l'enregistrement**, présenter, puis cliquer sur **Arrêter l'enregistrement**.
6. Retrouver la vidéo avec **Fichier** → **Afficher les enregistrements**.

Voir aussi [Introduction à OBS Studio](cours07.md#introduction-a-obs-studio) au cours 7.

## Questionnaire

### 1. Découverte de soi

- Quelles sont tes forces personnelles (créativité, organisation, logique, communication, curiosité, etc.)?
- Donne un exemple (une expérience vécue)
- Quelles sont tes faiblesses ou tes points à améliorer (difficulté à commencer un travail ou passer à une autre étape)?
- Donne un exemple (une expérience vécue)
- Préfères-tu travailler seul(e) ou en équipe? 
- Pourquoi? Donne un exemple (une expérience vécue)
- Te sens-tu plus à l'aise dans des tâches techniques (programmation, logiciels, organisation) ou créatives (dessin, montage, création visuelle ou sonore)?

### 2. Exploration des domaines

Pour chacun des domaines suivants, indique ton intérêt (faible, moyen ou fort) et explique pourquoi en une phrase :

- Graphisme
- Vidéo et animation 2D
- 3D
- Web
- Jeux vidéo
- Développement logiciel
- Installations et expériences immersives 

Ensuite, pour tes **2 domaines préférés**, réponds aux questions suivantes :

- As-tu déjà une expérience dans ce domaine (cours, projets, loisirs, bénévolat)? Si oui, explique en quelques mots. Si non, qu'est-ce qui pourrait t'aider à t'y initier?
- Quels logiciels, outils ou équipements connais-tu ou aimerais-tu apprendre?
- Pourquoi ce domaine t'intéresse-t-il?
- Te vois-tu travailler un jour dans ce domaine? Pourquoi?

"Exemple de réponse"  
    
    Domaine : photographie. J'ai déjà quelques années d'expérience en photographie puisque j'ai obtenu des contrats comme la couverture d'évènements ou de mariages.

    J'ai travaillé avec une caméra reflex T3i et l'équipement de base, comme la lentille 18-55 mm et le trépied. J'ai aussi travaillé avec de l'éclairage studio, mais j'aimerais surtout travailler avec des lentilles spéciales comme des macros.

    Mon intérêt pour ce domaine est très fort puisque j'adore utiliser le format visuel pour m'exprimer, transmettre un message ou raconter des histoires.

    J'aimerais vraiment travailler dans un petit studio qui réalise des projets dans des univers fictifs, par exemple une série d'affiches dans un univers de science-fiction.

### 3. Mon domaine préféré : ses caractéristiques

Pour ton domaine préféré, décris :

- les **types d'entreprises** qui y travaillent (voir [cours 6](cours06.md#types-dentreprises)) ;
- un **exemple d'entreprise** de ce type, avec son nom et une image représentative ;
- les **types de produits et de services** (voir [cours 6](cours06.md#types-de-produits-et-de-services)) ;
- les **étapes de production** d'un projet (voir [cours 7](cours07.md#les-etapes-de-production-dun-projet-multimedia)) ;
- le **type d'emploi** que tu aimerais y occuper ;
- les **étapes** pour obtenir cet emploi (formation, portfolio, stage, etc.).

### 4. Conclusion

- **Ton profil en une phrase** : comment te décrirais-tu comme futur(e) professionnel(le) du multimédia? (ex. : « Je suis une créative organisée qui veut concevoir des installations immersives. »)
- **Une surprise** : qu'as-tu découvert sur toi en répondant au questionnaire (une force, un intérêt ou un domaine auquel tu ne t'attendais pas)?
- **Le lien avec l'emploi visé** : quelle de tes forces t'aidera le plus dans l'emploi que tu vises, et quelle faiblesse dois-tu travailler en priorité?
- **Une action concrète d'ici la fin de la session** : un projet personnel, un tutoriel ou une compétence à ajouter à ta feuille de suivi.

## Critères d'évaluation

| Critère | Points |
|---|---|
| Clarté et structure de la capsule (introduction et conclusion) | /2 |
| Réflexion personnelle (questionnaire) | /5 |
| Caractéristiques du domaine préféré | /5 |
| Qualité de la capsule (son et image, enregistrée avec OBS) | /2 |
| Remise (page publiée et complète, capture OBS, fichier bien nommé) | /1 |
| **Total** | **/15** |

## Critères de performance

La distribution des points se fait selon les critères suivants :

| Critère de performance | Pourcentage |
|---|---|
| L'étudiant(e) a présenté une capsule complète, claire et pertinente. | 100 % |
| L'étudiant(e) a présenté une capsule complète, mais peu claire ou partiellement pertinente. | 75 % |
| L'étudiant(e) a présenté une capsule incomplète ou impertinente. | 50 % |
| L'étudiant(e) a présenté une capsule incomplète et impertinente. | 25 % |
| L'étudiant(e) n'a pas remis de capsule. | 0 % |

> N'oubliez pas que la qualité de la langue est évaluée jusqu'à concurrence de 10 % de la note finale du travail (1 % par faute).
