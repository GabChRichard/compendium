# Aide ménoire parametrage
## Caméra
### Mode

- Choisir l'icone film sur la molette de la caméra 

### Formater 

- Menu → Réglages : page 6/7
    - Formater

### Rétablirlesréglages de bases de la Caméra

- Menu → Réglages : page 6/7
    - Rétablir le réglge → Réinit. param. appar. photo

### Format de fichier

- Menu → Réglages prise de vue 2 : page 1/9
    - Format de fichier → XAVCS HD

### Film/ralenti + accél.

- Menu → Réglages prise de vue 2 : page 1/9
    - Film/ralenti + accél. → Exposit. Manuelle

### Réglage d'enregistrement

- Menu → Réglages prise de vue 2 : page 1/9
    - Réglage d'enreg. → 30p 50M

### Mise au point (focus)

- Menu → Réglages prise de vue 1 : page 5/14
    - Mode mise au point → MaP manuelle

### Enregistrement audio
> Activer le son seulement si on a besoin du son de la caméra.

- Menu → Réglages prise de vue 2 : page 2/9
    - Enregistrem. audio → *On ou Off dépendemment de si on veut le son de la caméra ou non*

### Balance des blancs

- Menu → Réglages prise de vue 1 : page 11/14
    - Temp./Filtre C. → *À ajuster selon l'éclairage*

### Zebra
> Activer seulement si on ne travail pas avec un tépiedou un stabilisateur (Ronin).

- Menu → Réglages prise de vue 2 : page 4/9
    - SteadyShot → Off

### Zebra
> Activer seulement si on ne travail pas avec un moniteur.

- Menu → Réglages prise de vue 2 : page 6/9
    - Zebra → *À ajuster selon vos besoin*

### Peaking
> Activer seulement si on ne travail pas avec un moniteur.

- Menu → Réglages prise de vue 1 : page 13/14
    - Niv. d'intensification → Élevé
    - Couleur d'intensification → *À ajuster selon vos gouts*

## Moniteur

### Son

- Menu 5 → Descendre le volume du moniteur à 0

### Zebra

- Menu 4 → Activer le overexposure (zebra)
    - *Ajuster le niveau du zebra selon vos besoins*
- Attribuer le overexposure(zebra) au bouton F2 du moniteur. 

### Peaking

- Menu 4 → Activer le focus assist (peaking)
    - *Ajuster le niveau d'intensification selon vos besoins*
- Attribuer le focus assist (peaking) au bouton F1 du moniteur. 

## Lite Panel

### Température

- *Ajuster la molette de température selon vos besoins.*

### Intensité

- *Ajuster la molette d'intensité selonvos besoins.*

## Sound Device

### Preset

- Menu Hamburger (1/3) → Presets
    - Load Preset → 3. ENG [Int4]

### Record Settings

- Menu Hamburger (2/3) → Record
    - Sample rate (1/2) → 48KHz
    - Bit Depth (2/2) → 24
